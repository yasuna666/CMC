# 西综病例-Skill 使用指南

> **一句话介绍**：用"临床工作流"替代"学科章节"，让病例分析题有迹可循
> **当前版本**：v2.2

---

## 快速开始

### 第一步：准备材料
确保你有以下文件：
```
你的项目文件夹/
├── 2025年真题_最终标准版.md      <- 必需
├── 教材/
│   ├── 内科学（第10版）_full.md   <- 必需
│   ├── 外科学（第10版）_full.md   <- 可选
│   └── ...
└── project.yaml                    <- Skill自动生成
```

### 第二步：激活Skill
对AI说以下任意一句话：
```
"分析2025年真题，创建病例工作流"
"做结核性腹膜炎的工作流"
"提取急性心衰的教材内容"
```

### 第三步：按提示操作
Skill会引导你：
1. **选择题目** -> 从真题列表中选要处理的题组
2. **确认内容** -> Skill提取教材后会展示，你确认或补充
3. **等待生成** -> 逐题处理，实时显示进度
4. **审核文档** -> 打开生成的.md文件，用审核清单逐项检查

## 核心概念

### 什么是"临床工作流"？

传统复习：翻教材 -> 读定义 -> 读病因 -> 读表现 -> 做题

工作流：打开"呼吸困难->急性左心衰.md" -> 看经典案例 -> 学决策链 -> 做训练题

**优势**：
- 按主诉组织（符合病例题出题逻辑）
- 整合真题（学完即练）
- 决策链条（诊断->检查->治疗的完整思维）

---

## 工作流文档结构（v2.2）

每个生成的文档包含五章：

| 章节 | 内容 | 用途 |
|------|------|------|
| **第1章：经典案例** | 完整真题题干 + 每题6要素解析 + 多题关联分析 | 学习标准解题思路 |
| **第2章：临床决策链** | 基于第1章的决策节点，引用教材原文 | 掌握完整诊疗流程 |
| **第3章：考点速查表** | 诊断标准 + 关键数值 + 易错点 | 考前快速复习 |
| **第4章：实战训练** | 3道历年真题（禁止AI编题） | 学完即练，检测掌握 |
| **第5章：考频分析与审核** | 历年考情 + 跨学科关联 + 四层审核清单 | 重点定位 + 质量保证 |

## 文件命名规则

```
临床工作流_{系统}-{编号}_{主诉}->{疾病}.md

示例：
临床工作流_GAST-001_腹胀->结核性腹膜炎.md
临床工作流_CARD-001_胸痛->急性心肌梗死.md
```

| 代码 | 系统 | 示例疾病 |
|------|------|----------|
| CARD | 心血管 | 心梗、心衰、心律失常 |
| RESP | 呼吸 | COPD、哮喘、肺栓塞 |
| GAST | 消化 | 溃疡、肝硬化、胰腺炎 |
| RENL | 泌尿 | 肾炎、肾病综合征 |
| HEMA | 血液 | 贫血、白血病、淋巴瘤 |
| ENDO | 内分泌 | 甲亢、糖尿病 |
| RHEU | 风湿免疫 | 类风湿、SLE |
| NEUR | 神经 | 脑梗、癫痫 |
| INF | 感染 | 结核、肝炎 |
| SURG | 外科 | 阑尾炎、肠梗阻 |

## 审核流程（重要！）

每个工作流生成后状态为"待审核"，你必须：

1. **打开文档**阅读
2. **对照审核清单**逐项打钩（四层：完整性/准确性/深度/专家级）
3. **特别注意**：检查所有 `verified: true/false` 标记，`verified: false` 的内容需人工核实教材
4. **确认无误**：修改YAML为 `status: 已审核`

**注意**：未审核的工作流仅供参考，不要直接用于复习！

## v2.2 关键特性

- **防幻觉机制**：所有教材引用标注 `verified: true/false`，禁止编造页码
- **训练题来源管控**：只用真题，禁止AI编造模拟题
- **错误模式库自增长**：处理新疾病时自动追加错误模式
- **进度追踪**：`.progress.yaml` 记录每个工作流的状态（waiting -> generated -> reviewed -> done）

## 重要提示

### 关于医学准确性
- Skill只提取教材原文，**不生成医学内容**
- 你必须**人工审核**，确保提取完整、无遗漏
- 药物剂量、诊断标准务必与教材核对
- `verified: false` 的引用**必须**人工验证

### 关于文件
- Skill自动处理UTF-8/GBK编码
- 建议不要频繁移动文件夹
