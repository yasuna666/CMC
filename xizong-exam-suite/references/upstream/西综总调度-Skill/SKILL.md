# 西综总调度-Skill v1.0

> **用途**：输入一份完整真题文件，自动识别题型分区，路由到对应Skill，批量调度生成  
> **定位**：5个题型Skill的上游调度器，不生成内容，只做分类和路由  
> **适用**：任意年份的西医综合真题文件

---

## 一、调度器职责

```
总调度器只做三件事：
1. 识别题型 — 把165题分到5个Skill
2. 生成映射 — 输出"题号→题型→Skill"对照表
3. 调度执行 — 按批次调用各Skill生成内容

总调度器不做：
× 不生成概念簇/工作流等内容（各Skill负责）
× 不做医学判断（各Skill+医学准确性规范负责）
× 不替代各Skill的SOP（只触发它们）
```

## 二、题型识别规则

### 2.1 识别流程

```
输入：一份完整真题 .md 文件
    ↓
Step 1: 定位B型题分界线
  搜索："B型题" 或 "共用备选项" 或 "每个选项可以被选择一次或两次"
  → 记录B型起始题号（如116）
    ↓
Step 2: 定位X型题分界线
  搜索："X型题" 或 "至少有两项是符合题目要求的"
  → 记录X型起始题号（如136）
    ↓
Step 3: 在A型题区间内定位共用题干
  搜索："共用题干" 或 "题共用题干"
  → 提取所有共用题干的题号范围（如68-70, 71-72, ...）
  → 这些题号 = A3/A4型
    ↓
Step 4: 在A型题区间内区分A1和A2
  对非共用题干的单选题，逐题判断：
  - 有"患者信息"（性别+年龄）+ 病例描述 → A2型
  - 纯知识点（无患者描述）→ A1型
  判断依据：题干中是否包含"男性/女性/男/女" + "岁" 的组合
    ↓
Step 5: 输出题型分布报告
```

### 2.2 A1 vs A2 的判断细则

```
A2型特征（必须同时满足）：
├── 有患者信息："男性/女性/男/女" + "数字+岁"
├── 有病例描述：症状/体征/检查结果
└── 非共用题干（不在Step 3的范围内）

A1型特征（满足任一）：
├── 无患者信息
├── 纯概念/机制/定义题
└── 临床医学人文/伦理题（通常在108-115区间）

边界情况处理：
├── 有"男性/女性"但只是一句话描述 → 仍可能是A2
├── 有年龄但无具体病例 → A1
└── 不确定时 → 标记为 "A1/A2待确认"，人工判断
```

### 2.3 B型题内部分组

```
在B型题区间内，按"共用选项"分组：
├── 找到选项定义（A/B/C/D四个选项的完整文字）
├── 找到该选项组关联的题目（通常2题）
├── 形成一个"选项组"
└── 重复直到B型区间结束

注意：下一个选项组的选项定义通常紧跟在上一组最后一题的解析之后
```

## 三、output目录结构

### 3.0 顶层结构

```
output/
├── 概念库/                    ← 活文档，同一概念只有一个文件，跨年累加
│   ├── A1概念簇/
│   │   └── by_subject/{科目}/{章节}/{文件}.md
│   ├── A2病例摘要/
│   │   └── by_system/{系统}/{文件}.md
│   ├── 病例工作流/
│   │   └── by_system/{系统}/{文件}.md
│   ├── B型配伍/
│   │   └── by_subject/{科目}/{文件}.md
│   └── X型多选/
│       └── {科目}/{章节}/{文件}.md
│
├── 年度报告/                  ← 每年一份，记录当年题型分布和处理状态
│   ├── 2025年题型分布报告.md
│   ├── 2025年批次执行清单.md
│   └── 2024年题型分布报告.md（后续追加）
│
├── 跨年汇总/                  ← 从概念库提取的统计和趋势
│   ├── 考频统计.md            ← 各概念/疾病被考查次数排名
│   ├── 易错类型趋势.md        ← XE/ME类型的年度分布
│   └── 科目覆盖分析.md        ← 各科目各章节的考查覆盖率
│
└── 全局索引.md                ← 跨题型、跨年份的总索引
```

**核心规则**：
- **概念库**中的文件是"活文档"——同一个概念（如钙泵）无论被2025和2024都考到，只有**一个文件**，新年份数据追加进去，考频自动累加
- **年度报告**是每年的快照——记录"这一年考了什么、路由到哪个Skill、处理到什么状态"
- **跨年汇总**由概念库自动生成——不手动维护，每次有新年份数据加入后重新统计

### 3.1 活文档跨年累加规则

当处理新年份真题时，遵循以下流程：

```
处理2024年某题（如钙泵相关题目）
    ↓
搜索概念库：是否已有"钙泵概念簇.md"？
    ├── 已有 → 追加模式
    │   ├── 在【真题呈现】/【真题档案】中追加2024年数据
    │   ├── 更新考频统计（count+1, years追加）
    │   ├── 追加新的陷阱模式（如有）
    │   └── 更新 updated_at
    └── 没有 → 新建模式
        └── 按Skill规范新建概念簇文件
```

**文件名不含年份**（因为是跨年累加的）：
```
✅ 生理学_细胞的基本功能_002_钙泵概念簇.md
❌ 2025_生理学_细胞的基本功能_002_钙泵概念簇.md
```

## 四、SOP流程

### Step 0: 定位真题文件

```
读取 project.yaml → paths.root + exam_files.current_year
→ 定位真题文件路径
```

### Step 1: 识别题型分区

按"二、题型识别规则"执行：
1. 搜索B型、X型分界标记
2. 搜索所有"共用题干"标记
3. 对非共用题干的A型题，逐题判断A1/A2
4. 生成题号→题型映射

### Step 2: 生成题型分布报告

按"三、3.2"格式输出到 `output/年度报告/{年份}年题型分布报告.md`

### Step 3: 生成批次执行清单

按"三、3.3"格式输出到 `output/年度报告/{年份}年批次执行清单.md`

### Step 4: 更新 .progress.yaml

在 `.progress.yaml` 中追加本次调度信息：
```yaml
routing_reports:
  - year: "2025"
    source_file: "2025年真题_最终标准版.md"
    generated_at: "2026-04-01"
    distribution:
      a1_count: 56
      a2_count: 20
      a3a4_groups: 15
      b_groups: 10
      x_count: 30
    batch_status:
      batch_1_a1: "待启动"
      batch_2_a2: "待启动"
      batch_3_a3a4: "待启动"
      batch_4_b: "待启动"
      batch_5_x: "进行中"
```

### Step 5: 按批次调度执行

**执行方式**：每个批次在独立对话中执行（避免上下文溢出）

**批次启动指令模板**：
```
请按 {Skill名称} 的SOP，处理{年份}年真题的以下题目：
- 题号范围：{题号列表}
- 真题文件：{年份}年真题_最终标准版.md
- 输出目录：output/概念库/{题型目录}/
- 活文档规则：先搜索概念库中是否已有同概念文件，有则追加，无则新建
- 参考：output/年度报告/{年份}年题型分布报告.md
```

**批次间衔接**：
- 每批次完成后更新 `.progress.yaml` 和批次执行清单
- 下一批次启动时读取上一批次的产出（用于跨Skill链接）

## 五、质量检查（调度层）

调度器自身的质量检查（不替代各Skill的质量检查）：

- [ ] 165题全部被分类（无遗漏）
- [ ] 共用题干题组的题号范围完整
- [ ] A1/A2分类合理（抽查3题确认）
- [ ] B型选项组分组正确
- [ ] 题型分布报告中的题数之和 = 165
- [ ] 已有产出（如X-136）正确标记为"已完成"

## 六、与其他Skill的关系

```
西综总调度-Skill（本Skill）
    │
    ├── 调用 → 西综A1概念簇-Skill v1.2
    ├── 调用 → 西综A2病例摘要-Skill v1.0
    ├── 调用 → 西综病例-Skill v2.2
    ├── 调用 → 西综B型配伍-Skill v1.0
    ├── 调用 → 西综X型多选-Skill v1.1
    │
    └── 参考 → 医学准确性规范.md（质量检查时引用）
```

**职责边界**：
- 总调度器：分类、路由、进度追踪
- 各题型Skill：内容生成、医学验证、质量检查
- 医学准确性规范：跨Skill共享的防护机制
