# 西综B型配伍-Skill v1.0

> **用途**：基于西医综合B型题（配伍题）生成配对概念簇  
> **核心创新**："选项组为中心" + "配对矩阵" + "双向匹配逻辑"  
> **适用题型**：B型题（配伍题，共用选项配对，题号不限，通过"共用备选项"标识识别）

---

## 零、B型配伍题 vs A1/A2题型对比

| 维度 | A1/A2型题 | B型题（本Skill） |
|------|-----------|-----------------|
| **题干结构** | 每题独立（题干+4选项） | 选项共用（选项组+多道题干） |
| **选项关系** | 每题选项独立 | 多道题共用一组选项（A/B/C/D） |
| **考查重点** | 知识点掌握 | **概念配对** + **相似概念鉴别** |
| **核心思维** | 单点判断 | **双向匹配**（选项↔题干） |
| **典型配对** | — | 机制-结果、疾病-部位、物质-功能 |
| **Skill单元** | 单题概念簇 | **选项组概念簇**（1组选项+多题） |

**B型的核心价值**：训练"相似概念的精确配对"能力

## 一、B型题识别与分组

### 1.1 识别特征

B型题在真题中的标识：
```
二、B 型题：（题号因年份而异，如近年为116~135小题）每小题1.5分，共30分。
A、B、C、D是其下两道小题的备选项，请从中选择一项最符合题目要求的，
每个选项可以被选择一次或两次。

【选项组1】116-117题共用
A. 血液pH升高，PaCO₂升高  
B. 血液pH升高，PaCO₂降低  
C. 血液pH降低，PaCO₂降低  
D. 血液pH降低，PaCO₂升高

116. 突然加快呼吸频率，潮气量不变，动脉血气分析结果是
117. 糖尿病酮症酸中毒时，动脉血气分析结果是

【选项组2】118-119题共用
A. 脊髓前角  
B. 纹状体  
C. 黑质  
D. 脊髓小脑

118. 帕金森病的中枢病变部位是
119. 意向性震颤的中枢病变部位是
```

### 1.2 分组规则

**以"选项组"为基本单元**，而非单题：

```
B型题（题号通过"共用备选项"标识动态识别，近年约为116-135题）
├── 选项组1：如116-117题（2题共用）
├── 选项组2：如118-119题（2题共用）
├── 选项组3：如120-121题（2题共用）
├── ...
└── 共约10个选项组（以实际真题为准）
```

**每个选项组生成一个概念簇文件**

## 二、五要素配伍概念簇结构

B型-Skill采用**五要素结构**（比A1/A2更简洁，聚焦配对）：

```
配伍概念簇文件结构（按选项组组织）
├── 【真题呈现】（选项组+所有关联题目）
│   ├── 共用选项（A/B/C/D完整定义）
│   ├── 题目1（题干+答案+解析）
│   ├── 题目2（题干+答案+解析）
│   └── ...（该组所有题目）
├── 【选项定义库】⭐ 核心
│   ├── 选项A精确定义
│   ├── 选项B精确定义
│   ├── 选项C精确定义
│   └── 选项D精确定义
├── 【配对矩阵】⭐ 核心创新
│   ├── 选项-考点对应表
│   ├── 题干特征提取
│   └── 匹配逻辑链
├── 【混淆预警】⭐ B型特色
│   ├── 相似选项对比（A vs B vs C vs D）
│   ├── 易混配对陷阱
│   └── 双向验证法
└── 【关联网络】（第五要素）
    ├── 关联A1概念簇（选项涉及的基础概念）
    └── 真题档案（考频+历年考查）

附属内容（不计入五要素）：
└── 【速记口诀】— 配对记忆技巧（可选）
```

## 三、五要素详细规范

### 3.1 【真题呈现】（选项组为中心）

**格式**：
```markdown
## 【真题呈现】（2025年选项组X：题号116-117）

### 共用选项（务必完整理解每个选项）
> **A. 血液pH升高，PaCO₂升高**  
> **B. 血液pH升高，PaCO₂降低**  
> **C. 血液pH降低，PaCO₂降低**  
> **D. 血液pH降低，PaCO₂升高**

### 题目1（116题）
**题干**：突然加快呼吸频率，潮气量不变，动脉血气分析结果是
**答案**：B
**解析**：①肺泡通气量=(潮气量-无效腔气量)×呼吸频率...（解析原文）
**配对逻辑**：呼吸加快→CO₂排出增加→PaCO₂降低→pH升高（呼吸性碱中毒）

### 题目2（117题）
**题干**：糖尿病酮症酸中毒时，动脉血气分析结果是
**答案**：C
**解析**：①糖尿病酮症酸中毒为严重的代谢性酸中毒...（解析原文）
**配对逻辑**：酮症酸中毒→代谢性酸中毒→pH降低→代偿性通气增加→PaCO₂降低
```

### 3.2 【选项定义库】⭐ 核心

**目的**：精确理解每个选项的含义，是配对的基础

**格式**：
```markdown
## 【选项定义库】

### 选项A：血液pH升高，PaCO₂升高
- **定义**：代谢性碱中毒伴呼吸代偿
- **机制**：原发HCO₃⁻升高→pH升高（碱中毒）→代偿性呼吸减慢→CO₂潴留→PaCO₂升高
- **典型场景**：严重呕吐（丢失HCl）、大量利尿、碱性药物过量
- **记忆点**："双高"→代谢性碱中毒（pH高是原发，PaCO₂高是呼吸代偿）
- **注意**：呼吸性酸中毒虽然也PaCO₂高，但pH是**降低**的，不是升高，不选A

### 选项B：血液pH升高，PaCO₂降低 ⭐正确答案（116题）
- **定义**：呼吸性碱中毒
- **机制**：肺泡通气过度→CO₂排出过多→PaCO₂降低→pH升高
- **典型场景**：呼吸频率加快（如本题）、癔症、低氧刺激
- **记忆点**："一高一低"，高pH低PaCO₂→呼吸太快

### 选项C：血液pH降低，PaCO₂降低 ⭐正确答案（117题）
- **定义**：代谢性酸中毒伴代偿性通气增加
- **机制**：固定酸增加→HCO₃⁻降低→pH降低→代偿性呼吸加快→PaCO₂降低
- **典型场景**：糖尿病酮症酸中毒、乳酸酸中毒、肾衰竭
- **记忆点**："双低"但pH低是原发，PaCO₂低是代偿

### 选项D：血液pH降低，PaCO₂升高
- **定义**：呼吸性酸中毒（急性）
- **机制**：急性肺泡通气不足→CO₂潴留→PaCO₂升高→pH降低（肾脏代偿来不及）
- **典型场景**：急性气道梗阻、溺水、呼吸中枢抑制（药物过量）、COPD急性加重
- **记忆点**：pH低+PaCO₂高 → 呼吸性酸中毒（通气不足，CO₂排不出）
```

### 3.3 【配对矩阵】⭐ 核心创新

**目的**：建立"题干特征↔选项"的精确匹配关系

**格式**：
```markdown
## 【配对矩阵】

### 题干特征-选项匹配表

| 题干关键词 | 生理/病理过程 | 推导逻辑 | 匹配选项 | 排除选项 |
|-----------|--------------|----------|----------|----------|
| **呼吸频率加快+潮气量不变** | 肺泡通气量增加 | 通气↑→CO₂排出↑→PaCO₂↓→pH↑ | **B** | A/C/D |
| **糖尿病酮症酸中毒** | 代谢性酸中毒 | 酮酸↑→HCO₃⁻↓→pH↓→代偿性通气↑→PaCO₂↓ | **C** | A/B/D |

### 选项特征速查

```
选项A [pH↑, PaCO₂↑]：代谢性碱中毒伴呼吸代偿
                    → 严重呕吐、大量利尿等
                    
选项B [pH↑, PaCO₂↓]：⭐ 呼吸性碱中毒
                    → 呼吸过快/过度通气
                    
选项C [pH↓, PaCO₂↓]：⭐ 代谢性酸中毒（代偿）
                    → 酮症、乳酸中毒、肾衰
                    
选项D [pH↓, PaCO₂↑]：呼吸性酸中毒（急性）
                    → 呼吸抑制/气道梗阻
```

### 配对逻辑链示例

**116题配对链**：
```
[呼吸频率加快] → [肺泡通气量增加] → [CO₂排出增加] 
                                                  ↓
[pH升高] ← [H⁺浓度降低] ← [PaCO₂降低] ←——┘
        ↓
    选项B ✅
```

**117题配对链**：
```
[糖尿病酮症酸中毒] → [酮体堆积] → [代谢性酸中毒] → [HCO₃⁻消耗]
                                                              ↓
[PaCO₂降低] ← [代偿性呼吸加快] ← [pH降低] ←——————┘
        ↓
    选项C ✅
```
```

### 3.4 【混淆预警】⭐ B型特色

**目的**：B型题最容易混淆"相似选项"，需要专项预警

**格式**：
```markdown
## 【混淆预警】

### 模式1：相似选项混淆⭐⭐⭐最高频

**陷阱**：B和C都是"一高一低"，容易混淆
- **B**：[pH↑, PaCO₂↓] → pH高是原发（呼吸性碱中毒）
- **C**：[pH↓, PaCO₂↓] → pH低是原发（代谢性酸中毒）

**区分技巧**：
```
看pH方向：
├─ pH > 7.45（升高）→  alkalosis（碱中毒）
│                      ↓
│                 看PaCO₂：
│                 ├─ PaCO₂↓ → 呼吸性（B）
│                 └─ PaCO₂↑ → 代谢性（A）
└─ pH < 7.35（降低）→  acidosis（酸中毒）
                       ↓
                  看PaCO₂：
                  ├─ PaCO₂↓ → 代谢性（C）
                  └─ PaCO₂↑ → 呼吸性（D）
```

### 模式2：原发vs代偿混淆⭐⭐

**陷阱**：PaCO₂降低可以是原发（呼吸性碱中毒）或代偿（代谢性酸中毒）

**判断原则**：
- pH方向决定原发紊乱
- PaCO₂方向与原发一致→原发
- PaCO₂方向与原发相反→代偿

**本题应用**：
- 116题：pH↑（碱中毒），PaCO₂↓（降低）→ 同向→呼吸性碱中毒（B）
- 117题：pH↓（酸中毒），PaCO₂↓（降低）→ 反向→代谢性酸中毒代偿（C）

### 模式3：只看一个指标⭐

**陷阱**：只看PaCO₂或只看pH
**错误示例**：
- "PaCO₂降低就是呼吸性碱中毒"→错！也可能是代谢性酸中毒代偿
- "pH升高就是碱中毒"→对，但分不清呼吸性还是代谢性

**正确做法**：必须两个指标一起看，结合题干病因
```
题干：呼吸频率加快 → 直接影响PaCO₂ → 呼吸性
题干：糖尿病酮症 → 直接产酸影响pH → 代谢性
```

### 模式4：选项重复使用困惑

**题目说明**："每个选项可以被选择一次或两次"

**策略**：
- 不要被"只能用一次"限制思维
- 如果两道题确实都指向同一选项，大胆选
- 但B型一般设计为不同答案（如116-B，117-C）
```

## 四、SOP流程

### Step 1: 识别选项组
- 通过"A、B、C、D是其下两道小题的备选项"标识定位B型题区间（**不依赖固定题号**）
- 按"共用选项"分组
- 每组提取：选项A/B/C/D + 关联的所有题目
- 生成选项组清单（输出到日志）

### Step 2: 生成配伍概念簇

**输出路径**：`output/概念库/B型配伍/by_subject/{科目}/`

**活文档规则**：文件名不含年份。处理新年份时，先搜索是否已有同主题选项组文件：有则追加新年度数据（更新考频），无则新建。

- 为每个选项组建一个概念簇文件
- 填充五要素：真题呈现→选项定义→配对矩阵→混淆预警→关联网络

### Step 3: 教材原文检索【带验证】

**来源验证规则**：
每个选项的定义、机制、典型场景，**必须**与教材内容核对，标记 `verified: true/false/no_source`。

**严禁**：
- 禁止凭记忆编造教材页码或原文
- 禁止编造疾病的血气分析特征、病变部位等关键事实
- 禁止编造"历年类似考题"的具体年份和题号
- 无法验证必须标注 `⚠️ 待验证`

### Step 4: 质量检查【四层】

**第一层：完整性审核**
- [ ] 每个配伍概念簇包含五要素
- [ ] 每个选项都有完整定义
- [ ] Frontmatter信息完整
- [ ] 文件名符合规范

**第二层：医学准确性审核（最重要）**
- [ ] 每个选项的定义与教材一致（酸碱平衡方向、病变部位、物质功能等）
- [ ] pH方向与酸碱中毒类型对应正确（pH↑=碱中毒，pH↓=酸中毒）
- [ ] 原发 vs 代偿的判断逻辑正确
- [ ] 教材引用有 `verified:` 标记
- [ ] 无AI编造内容

**B型特有高危点（遵循 `Skills/医学准确性规范.md`）**：
- [ ] 每个选项的方向性指标（升高/降低）必须与定义一致，反向核查（ME-02）
- [ ] 选项定义不能把"酸中毒"归为pH升高、不能把"碱中毒"归为pH降低
- [ ] 原发变化 vs 代偿变化必须明确标注，不能混为一谈（ME-03）
- [ ] 速记口诀中的每个要素必须与选项定义一致，不能写反（ME-07）
- [ ] 疾病-部位配对（如帕金森-黑质）必须核对教材（ME-01）

**第三层：逻辑审核**
- [ ] 配对矩阵的匹配逻辑链完整通顺
- [ ] 混淆预警覆盖最易混淆的选项对
- [ ] "双向验证"：从题干→选项 和 从选项→题干 都能成立

**第四层：可用性审核**
- [ ] 与A1概念簇的链接有效
- [ ] 可通过Obsidian标签/文件名/Grep检索
- [ ] 速记口诀准确且不会引起误导

### Step 5: 进度追踪

生成 `.progress.yaml` 条目，B型专用字段：
```yaml
concept_clusters:
  - id: "B-01"
    option_theme: "血气分析与酸碱平衡"
    subject: "生理学"
    source_questions: ["2025-116", "2025-117"]
    pairing_type: "机制-结果配对"      # B型专用：配对类型
    options_count: 4                    # 选项数量
    linked_a1_clusters: ["酸碱平衡", "呼吸调节"]
    status: "waiting"
    verified_sources: 0
    unverified_sources: 0
```
