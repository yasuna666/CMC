# 西综A2病例摘要-Skill v1.0

> **用途**：基于西医综合A2型题（病例摘要型单选题）生成病例摘要概念簇  
> **核心创新**："诊断思路可视化" + "病例↔基础概念双向链接" + "鉴别诊断矩阵"  
> **适用题型**：A2型题（病例摘要型单选题，题号不限，通过内容识别）

## 零、A2病例摘要 vs A1/A3题型对比

| 维度 | A1型题 | A2型题（本Skill） | A3/A4型题（病例-Skill） |
|------|--------|-------------------|------------------------|
| **题干长度** | 一句话（<30字） | 简短病例（50-150字） | 完整病例（200-500字） |
| **病例信息** | 无 | 有（患者+症状+检查） | 有（详细病历） |
| **问题数量** | 1问 | 1问 | 3-4问 |
| **考查重点** | 知识点记忆 | 知识应用+初步诊断 | 临床思维链条 |
| **Skill结构** | 六要素 | 六要素（病例导向） | 五章（工作流导向） |
| **核心目标** | 概念网络 | 病例→诊断→概念 | 完整临床决策流程 |

**A2的核心价值**：从"纯知识点"到"病例情境应用"的桥梁

## 一、A2病例型的识别与分类

### 1.1 识别特征

A2型题题干通常包含：
```
【患者信息】性别、年龄（有时含职业/既往史）
↓
【主诉】主要症状+持续时间
↓
【关键检查】实验室/影像学/体征（选择性呈现）
↓
【问题】诊断？/首选检查？/最佳治疗？
```

**与A1的区分**：A2有明确的"患者"和"病例描述"；A1是抽象知识点。

### 1.2 内部分类

| 子类型 | 占比 | 考查重点 | 示例 |
|--------|------|----------|------|
| **诊断型**（60%） | 最高 | 根据病例信息做出诊断 | "最可能的诊断是" |
| **检查型**（25%） | 中 | 选择首选/确诊检查 | "为明确诊断，首选" |
| **治疗型**（15%） | 低 | 选择最佳治疗方案 | "最佳治疗药物是" |

### 1.3 与A3/A4的区分

**关键判断**：是否"共用题干"？
- 是 → A3/A4（用西综病例-Skill处理）
- 否 → A2（用本Skill处理）

## 二、七要素病例摘要簇结构

A2-Skill采用**七要素结构**（在A1六要素基础上增加【诊断思路】）：

```
病例摘要簇文件结构（按顺序）
├── 【真题呈现】（最前置）
│   ├── 完整病例
│   ├── 问题
│   ├── 正确答案
│   ├── 详细解析
│   └── 陷阱分析
├── 【诊断思路】⭐ 新增核心要素
│   ├── 病例信息提取表
│   ├── 关键线索标记
│   ├── 诊断推理链
│   └── 鉴别诊断排除
├── 【核心概念】
│   ├── 目标疾病定义
│   └── 关键诊断标准
├── 【教材原文】
│   └── 诊断标准+治疗原则（verified）
├── 【鉴别诊断矩阵】⭐ 改造自"概念簇对比"
│   ├── 相似疾病对比表
│   └── 关键鉴别点（为什么不是其他病）
├── 【干扰预警】
│   ├── 病例信息陷阱
│   ├── 检查选择陷阱
│   └── 治疗时机陷阱
└── 【真题档案】（第七要素）
    ├── 考频统计
    ├── 关联A1概念簇（双向链接）⭐
    └── 关联A3/A4工作流（如有）⭐

附属内容（不计入七要素）：
└── 【速记卡片】— 诊断要点速记（可选）
```

## 三、七要素详细规范

### 3.1 【真题呈现】（最前置）

**位置**：Frontmatter之后  
**要求**：100%复制真题原文，一字不减

**格式**：
```markdown
## 【真题呈现】（2025年第42题）

### 完整病例
> **女性，23岁。因腰痛1周行尿常规沉渣镜检，发现红细胞20～40个/HPF,98%形态多样、大小不一。**

### 问题
> **首先可排除的疾病是**

### 选项
> A. 肾盂肾炎  
> B. 肾小球肾炎  
> C. 肾结石  
> D. 肾结核

### 正确答案
**A**

### 详细解析
①离心尿液中红细胞>3个/HPF，称为镜下血尿...（保持真题解析原文）

### 陷阱分析
| 选项 | 陷阱类型 | 分析 |
|------|----------|------|
| B/C/D | 疾病混淆 | 均表现为肾小球源性血尿，不是"排除"对象 |
```

---

### 3.2 【诊断思路】⭐ 核心创新

**目的**：可视化展示"从病例到诊断"的思维过程

**格式**：
```markdown
## 【诊断思路】

### 病例信息提取表

| 信息类型 | 具体内容 | 诊断价值 |
|----------|----------|----------|
| **患者特征** | 女性，23岁 | 青年女性，考虑常见病因 |
| **主诉** | 腰痛1周 | 提示泌尿系统疾病 |
| **关键检查** | 红细胞20～40个/HPF | 镜下血尿 |
| **关键特征** | 98%形态多样、大小不一 | ⭐ 非均一性红细胞 = 肾小球源性 |

### 关键线索标记

```
【核心线索】非均一性红细胞占98%
    ↓
【病理意义】肾小球源性血尿
    ↓
【疾病范围】肾小球肾炎（最符合）；肾结石、肾结核也可引起血尿但通常为均一性
    ↓
【排除逻辑】肾盂肾炎主要引起脓尿，不是血尿 → 首先排除
```

### 诊断推理链

1. **发现异常**：镜下血尿（RBC 20-40个/HPF）
2. **鉴别血尿类型**：非均一性红细胞>50% → 肾小球源性血尿
3. **定位诊断**：病变在肾小球
4. **分析选项**：
   - 肾小球肾炎：肾小球源性血尿，非均一性RBC ✓ 最符合
   - 肾结石：通常为非肾小球源性（均一性RBC），但不能完全排除
   - 肾结核：通常为非肾小球源性（均一性RBC），但不能完全排除
   - 肾盂肾炎：肾间质感染，主要引起**脓尿**而非血尿 ✗ 首先排除
5. **得出结论**：肾盂肾炎最不符合，首先排除

### 鉴别诊断排除

| 疾病 | 是否可能 | 排除/保留理由 |
|------|----------|---------------|
| 肾小球肾炎 | **最可能**（保留） | 典型表现为肾小球源性血尿（非均一性RBC） |
| 肾结石 | 不太符合但不能排除 | 通常引起非肾小球源性血尿（均一性RBC），但仍可能伴血尿 |
| 肾结核 | 不太符合但不能排除 | 通常引起非肾小球源性血尿（均一性RBC），但仍可能伴血尿 |
| 肾盂肾炎 | **首先排除** | 主要表现为**脓尿**（白细胞尿），而非血尿 |
```

### 3.3 【核心概念】

**与A1的区别**：聚焦"疾病诊断"而非"抽象概念"

**格式**：
```markdown
## 【核心概念】

**目标疾病：肾盂肾炎**
- **定义**：肾盂黏膜及肾实质的急性或慢性炎症
- **主要表现**：发热、腰痛、膀胱刺激征 + **脓尿**（不是血尿）
- **尿特点**：白细胞尿、白细胞管型，红细胞少见

**关联概念：肾小球源性血尿**
- **定义**：红细胞经肾小球滤过膜挤压变形
- **特点**：非均一性红细胞>50%，形态多样、大小不一
- **常见病因**：肾小球肾炎、肾结石、肾结核、多囊肾等
```

### 3.5 【鉴别诊断矩阵】⭐ 改造自A1的"概念簇对比"

**目的**：解释"为什么不是其他选项"

**格式**：
```markdown
## 【鉴别诊断矩阵】

### 血尿病因鉴别

| 疾病 | 病变部位 | 血尿类型 | 尿RBC形态 | 其他特点 | 是否符合本病例 |
|------|----------|----------|-----------|----------|----------------|
| **肾盂肾炎** | 肾间质 | 少见 | — | **脓尿**、白细胞管型、发热 | ❌ **首先排除**（本例是血尿，非脓尿） |
| 肾小球肾炎 | 肾小球 | 典型 | **非均一性** | 蛋白尿、管型尿 | ✅ **最符合**（98%非均一性RBC） |
| 肾结石 | 肾盏/肾盂 | 常见 | **均一性** | 绞痛、影像学阳性 | ⚠️ 不太符合（RBC应为均一性）但不能完全排除 |
| 肾结核 | 肾实质/集合系统 | 常见 | **均一性为主** | 结核中毒症状、脓尿 | ⚠️ 不太符合（RBC应为均一性）但不能完全排除 |

### 关键鉴别点

**为什么排除肾盂肾炎？**
- 核心依据：肾盂肾炎主要引起**脓尿**（白细胞尿），而非血尿
- 本例特点：以血尿为主，98%非均一性红细胞
- 结论：不符合肾盂肾炎的典型表现

**为什么不能排除B/C/D？**
- 这三种疾病均可引起肾小球源性血尿
- 仅根据"非均一性血尿"无法区分
- 需要更多检查（如B超、尿培养、肾穿）
```

### 3.6 【干扰预警】

**A2特色陷阱**：

```markdown
## 【干扰预警】

### 模式1：疾病-表现张冠李戴⭐
- **陷阱**："腰痛+血尿"→默认想到肾盂肾炎
- **错误逻辑**：腰痛=肾盂肾炎（忽视血尿特点）
- **正确逻辑**：腰痛+血尿→先看血尿类型→再定病因

### 模式2：检查信息误读
- **陷阱**：只看到"红细胞"，没看到"形态多样"
- **关键**：非均一性红细胞>50%是诊断核心
- **误读后果**：忽略肾小球源性/非肾小球源性的鉴别

### 模式3：排除法逻辑错误
- **陷阱**：选"最可能的诊断"而不是"可排除的疾病"
- **审题关键**：题目问"可排除"，不是"最可能"
- **逻辑反转**：找"不符合"的选项，不是找"符合"的
```

## 四、SOP流程（引导式交互）

### Step 0: 配置确认
- 选择年份（如2025）
- A2题识别方式：**通过内容特征识别**（有患者+病例描述+单问），不依赖固定题号区间
- 区分：纯知识型（转A1处理） vs 病例摘要型（本Skill处理）

### Step 1: 真题解析与分类
**任务**：
1. 读取全部A型题，通过内容特征筛选A2病例摘要型：
   - 有"患者信息"（性别、年龄）→ 可能是A2
   - 有病例描述但**非**"共用题干" → 确认为A2
   - 无病例描述 → 转A1-Skill处理
   - "共用题干"多问 → 转病例-Skill处理
2. 分类已识别的A2题（诊断型/检查型/治疗型）
3. 提取病例信息（患者/症状/检查）

### Step 2: 病例摘要簇生成
**任务**：
1. 识别诊断类型（诊断型/检查型/治疗型）
2. 生成【诊断思路】（核心步骤）：病例信息提取表 → 关键线索 → 推理链 → 鉴别排除
3. 生成【鉴别诊断矩阵】：必须解释"为什么不是其他选项"
4. 建立与A1概念簇的双向链接

### Step 3: 教材原文检索【带验证】

**来源验证规则（边写边验证）**：
每引用一处教材内容，**立即**用 Read/Grep 工具读取教材文件验证，并标记 `verified: true/false/no_source`。

**严禁**：
- 禁止凭记忆编造教材页码
- 禁止伪造教材原文
- 禁止编造疾病的临床表现或鉴别要点
- 无法验证必须标注 `⚠️ 待验证` 而非写一个看似合理的内容

### Step 4: 质量检查【四层】

**第一层：完整性审核**
- [ ] 每个病例摘要簇包含七要素
- [ ] Frontmatter信息完整
- [ ] 文件名符合规范

**第二层：医学准确性审核（遵循 `Skills/医学准确性规范.md`）**
- [ ] 鉴别诊断矩阵中的疾病特征与教材一致
- [ ] 血尿/脓尿/蛋白尿等检查特征归属正确
- [ ] 疾病的病变部位、典型表现无张冠李戴
- [ ] 教材原文有 `verified:` 标记
- [ ] 无AI编造内容

**A2特有高危点**：
- [ ] 检查特征归属：血尿类型（肾小球源性=非均一性 vs 非肾小球源性=均一性）必须与病变部位对应
- [ ] 解析中的症状描述必须与原题干完全一致（如原题"无胸痛"不能写成"胸痛"）
- [ ] 首选检查 vs 金标准检查不可混淆（金标准≠首选）
- [ ] 鉴别诊断中"排除"和"保留"的理由必须与病例信息对应

**第三层：逻辑审核**
- [ ] 【诊断思路】推理链逻辑通顺
- [ ] 【鉴别诊断矩阵】解释了"为什么不是其他选项"
- [ ] 排除/保留理由与病例信息对应

**第四层：可用性审核**
- [ ] 与A1概念簇的链接有效
- [ ] 可通过Obsidian标签/文件名/Grep检索
