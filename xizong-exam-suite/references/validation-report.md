# v2 桥接与学习闭环验证记录

验证日期：2026-10-16。对象为统一入口、薄适配协议、exam_tool.py、learning_bridge.py 和 learning_loop.py。原六模块字节不变，未执行原辅助脚本。

## 可复现工程检查

工具负责检查项目配置、来源索引、题库结构、桥接哈希、独立复核记录、导出隔离和作答绑定。`assets/upstream-manifest.json` 保存上游文件哈希；真实项目应在自己的讲义、教材和作答记录上执行完整流程。

校验只证明文件绑定和结构门槛，不证明医学事实、审核身份或学习效果。真实用法和桥接 v1 迁移见 usage.md、upstream-bridge.md。

## 限制

工程检查不构成真实西综医学质量验收。未使用用户真实讲义，未验证特定年度考纲、扫描件或复杂 DOCX 图表。结构化字段和文件哈希不能证明医学事实正确、AI 真正采用了产物或作答者/审核者身份；仍须真实来源核对与独立审题。

反馈以绑定答案为准；草稿答案只产生暂定反馈，不更新真题考频或掌握统计。variation_note 的实质性由审题流程判断，脚本不能证明变式确实测量了新能力。
