## 复现

在套件根目录运行：

```bash
python3 -B tests/test_exam_tool.py
python3 scripts/exam_tool.py demo --workspace ../xizong-demo
```

演示输出目录必须尚不存在。真实讲义的配置与命令见 [使用说明](usage.md)。
